Height change at same weight & font-size

All lines use the same font (Inter), same font-size (3rem), same font-weight (700). Only transform: scaleY(...) changes, so you see height stretch/squash only.

scaleY(0.8) — shorter

transform: scaleY(0.8)

scaleY(1) — normal

transform: scaleY(1)

scaleY(1.25) — taller

Boston'a dershane açıyoruz
transform: scaleY(1.25)

scaleY(1.5) — taller

Boston'a dershane açıyoruz
transform: scaleY(1.5)

scaleY(2) — twice the height

Boston'a dershane açıyoruz
transform: scaleY(2)

This uses CSS transform: scaleY(), not a variable font axis. Variable fonts with a true “vertical scale” axis are rare; scaleY is the usual way to get this effect with any font.
